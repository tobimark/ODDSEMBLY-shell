## 4. 后续规则

1. Loom 左框 484；右缘不超过 1430（730 宽下 ≥20 CSS 余量）。
2. 齿轮箱右缘不超过 410；与 Loom 间隙 ≥70。
3. 导管 x ≤ 245 且 ≥ 170，不得进入卡窗区域（x<132）。
4. 传动轴只占上方一条；下方结构轨保留，不新增第三条大连接。
5. 张力管必须两端落在实体上；悬空即删除，不补装饰线。
6. 底部内容保持在 510–520（730×548 下 28–38px 余量）。
7. 不新增控制箱、灯带、粒子、HUD 或大片发光。
