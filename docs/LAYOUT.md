# Loom 场景构图与 CrommaCode 壳尺寸

本文件固定「设计空间 1472×1008 → 真实 GameView 730×495」的换算关系，以及
**齿轮机械 / Loom 主体 / 转盘** 三个视觉对象的比例和禁入区。所有数字以设计 px 为准，
括号内为壳内实际 CSS px。

## 1. 壳的尺寸事实

依据 `kunlun-shell/src/geometry.ts`、`CanvasWell.tsx` 与
`CrommaCode-GameView-视觉实现逆向.md` §7.1：

| 项 | 尺寸（CSS px） | 说明 |
|---|---|---|
| 舞台 stage | 1453×865 | 壳的 1:1 参考帧 |
| client | 1440×852 @ (6.5,6.5) | 标题栏/侧栏/主体 |
| CanvasWell | 730.5×743 @ client (265,100) | GameView 的空井 |
| **实际 GameView 画布** | **730×495** | 位于井顶部；模式栏浮在其上 |
| 模式栏 | 730×30 | 覆盖画布顶部 30 px |
| HUD / 四卡 | 从 stage y≈668 起 | 在画布下方，不覆盖场景 |

换算：

```
设计 1472×1008  →  显示 730×495
scaleX = 730 / 1472 = 0.4959
scaleY = 495 / 1008 = 0.4911   (差 1%，按 fit-cover 或 730×500 居中处理)
```

**结论：设计里 1 px ≈ 壳内 0.5 px；任何要读的文字/线宽必须按 0.5× 预判。**

## 2. 三分区（设计 px）

| 区域 | bbox（设计 px） | 显示尺寸（CSS） | 缩放 | 内容 |
|---|---|---|---|---|
| **DIAL 转盘** | x 0–470, y 0–520（可见弧带，向左下延伸） | 233×258 | 0.83 | 外环带、蓝弧、卡窗、读头、读数器 |
| **GEAR 齿轮组** | x 270–474, y 480–775 | 101×146 | 1.0 | 飞轮 + 两级齿轮 + 传动杆 |
| **LOOM 主体** | x 484–1430, y 130–890 | 469×377 | 1.0 | 织机框、经线、织物、伺服、仪表 |
| **READOUT** | 显示 x 20–195, y 75–155 | 87×40 | 0.83 | 盘面悬架读数器 |

间距：

- DIAL → LOOM 顶部间隙 **17 px**（显示 ≈8 px）；中段 ≥100 px。
- GEAR → LOOM 左框间隙 **4–10 px**（显示 2–5 px）；齿轮组不进入 Loom 框内。
- LOOM → 画布右边距 **42 px**（显示 ≈21 px）。
- READOUT 顶边到画布顶 **75 px**（显示 37 px），减去模式栏 30 px，实际露出间隙 **7 px**。
- LOOM 底边到画布底 118 px；HUD 从画布下方开始，不覆盖。

三个对象**没有像素级互相遮挡**；DIAL 的可见弧带从画布左上切入，GEAR 在其下方，
LOOM 从 x=484 起独立成块。

## 3. 读数器的可读性预算

读数器设计 `210×94`，经盘面 0.83 缩放后约 `174×78`，显示约 **87×40 CSS**。

| 元素 | 设计字号 | 显示字号 | 结论 |
|---|---|---|---|
| TYPE（READ/BASH/…） | 44 | **18.1 px** | 主信息，清晰 |
| ×N | 22 | **9.1 px** | 可读，建议不低于 22 |
| Sxx / 12 | 22 | **9.1 px** | 可读；与 ×N 同一行 |
| 标题 `EVENT / 01` | — | — | **已删除**，不再占一行 |

规则：场景内要传达状态的文字，设计字号 **≥20 px**（显示 ≥9 px）；主数值 ≥40 px。
Loom 上 7–13 px 的铭牌/刻度只作纹理，不作为信息。

## 4. 后续改动规则

1. **Loom 左框线固定在 x=484**（设计）；任何新对象不得越过它进入 Loom 区。
2. **转盘缩放上限 0.85**：再放大时外环在 Loom 顶边 y=130 处必须仍 < x=484。
3. **Loom 缩放不低于 0.95**；若缩小，保持左框 ≥480、右边距 ≥30。
4. 齿轮组属于 Loom 世界，缩放随 Loom；不得让飞轮右缘越过 Loom 左框 + 0。
5. 顶部 0–60 px（显示 0–30 px）是模式栏覆盖区，不放关键读数；读数器顶边保持 ≥65 px。
6. 不新增控制台/灯带/粒子；新增信息优先放壳的 Agent/Tool Stream，不放进场景。
