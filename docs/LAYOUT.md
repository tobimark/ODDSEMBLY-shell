# Loom 场景构图与视觉层级（layout v6）

V6 是**视觉质量整改**，不改事件状态机、12 槽索引、30° 步进、工具配色和织物纹样。
本轮重点：730px 实际尺寸下的可读性、读数器形态、机械连续性、导管精简、右侧边界。

## 3. 读数窗

- 245×100，盘面局部 `(80,170)`；水平、不旋转、不在床身上。
- 单一外壳轮廓 + 一个内凹窗口；**没有**双层 bezel、安装轨、悬挂夹具或连杆。
- 只显示：工具名 / ×N / Sxx / 12。SEARCH 已验证不截断。
- 层级在读数器 front，固定在盘面上，不随转子转动。

## 5. V6 视觉层级（LOD）

**删除/精简**

- 全幅 24px 点阵、4 条目录小字、顶部 FIG/口号、读数器双层边框/安装轨/夹具/连杆。
- 导管由 8 点减到 5 点，3 夹减到 2 夹，去掉逐折点接头。
- 联轴器两侧的安装板堆叠；螺栓的六角细节在 0.5x 下不再绘制。
- 右侧伺服外伸曲柄组向内收，pick 计数移入框架。

**弱化**

- 上层经线 alpha 0.58；小于 8px 的微标签统一 0.58 alpha；装饰性细线不再加粗。
- 螺栓简化为安静的点状紧固件，不再画不可见的螺纹。

**强化**

- 主框外轮廓 1.8px；结构 plate 外轮廓 1.5px。
- 读数窗字号和对比度；SEARCH 兼容。
- 输出轴连续中心线、联轴器键、输出轴承；键随齿轮相位旋转（3×）。
- 品牌统一：床身 `ODDSEMBLY`，机架 `ODDS / 01`，图纸 `ODDSEMBLY / EVENT LOOM 01`。
