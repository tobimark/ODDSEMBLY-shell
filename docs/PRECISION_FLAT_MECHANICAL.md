# Precision Flat Mechanical · 视觉规范 01

适用范围：KunlunMeta Loom 及其左侧事件刻度机构。本轮不扩展其他 Game View。

## 视觉原则

画面视为一台正投影精密设备。通过截面、装配边界、凹槽、紧固件和前后遮挡表达结构，而不依靠透视挤出、镜面渐变、厚阴影或整体透明化。刻度壳、控制箱、机架和驱动附件必须使用同一套表面与紧固件。

## 表面与线条

设计空间 1472×1008；尺寸单位为设计像素。核心 token 位于 `src/engine/modes/loom/atelier/finish.ts`。

| 用途 | 规范 |
|---|---|
| 纸面 / 陶瓷 | `#FBF9F6`，保持亮但不发光 |
| 搪瓷壳体 | `#F5F3EC`，单层面，内侧折边约 3 px |
| 平面钢件 | `#E8E8E0`，用窄回边而不是圆柱镜面渐变 |
| 凹槽 / 安装槽 | `#DEDCD2`，真实闭合几何，细描边 |
| 主结构 / 刻度 / 品牌 | Navy `#171C60`，窄线、局部铭牌与基准弧；不铺满立柱 |
| 活动反馈 | Teal `#33CBCC`，用于梭芯、事件纬线、活动定位点 |
| 轮廓 | 灰 `#9A9E9E`，约 0.75 px；承重框边用 `#78818A` |
| 次级分缝 | `#C4C6BE`，约 0.45–0.6 px |
| 基准线 | 约 1.1 px；与次级分缝拉开层级 |
| 局部浅浮雕 | 约 1.2 px；阴影 `#171C600D`，只落在零件接触处 |
| 高光 | `#FFFDF8`，单根 0.6 px 边线，不能成为宽亮带 |

零件细则：

- **立柱**：折边薄壳、内凹导轨床、腰形安装孔；用狭窄基准线保留承重识别，不画厚实蓝色侧面。
- **横梁和导轨**：平面钢材 web、单侧回边、接缝与轴承座。不使用六段金属渐变。
- **螺栓**：沉入式浅座、六角/槽口细线，统一圆形垫圈；不要把每枚螺栓做成高对比亮球。
- **轴承**：按安装板—座圈—压环—轴端叠层，依赖多圈线宽和材料变化区分。
- **齿轮与飞轮**：保留齿数、轮缘、细辐条、减重孔和偏心定位点。孔是透明切口；Navy 只描轮缘和轴向标记。
- **纱筒**：真实轴芯、端盘、绕线和出纱扇形；纤维线覆盖暖白底，不画金属光柱。顶横架需有落在机架上的立脚。
- **织物**：保留 112 根经线、斜纹交点与事件行，降低预设纹样的大面积深色对比。不能用模糊或统一低透明度替代组织结构。
- **标注**：全景 6–9 px 的次要说明只用于识别，详细阅读依赖 Detail/高清图；状态文本不可压在轴承、连杆上。

## 共同装配

1. `integration.ts` 提供贯通底座，承接控制箱安装脚和织机机脚；它是一根固定装配梁，不是假传动轴。
2. 大刻度**固定外壳**通过切向鞍座和横向支架与织机左框连接。避免把支架解释为夹住运动圆盘。
3. 控制箱与驱动盒之间设固定连接耳板，端面孔位与壳体对齐。
4. 读头的软管从切向滑架的实际关节引出；使用其旋转变换后的端点，不用错误的纯径向近似。
5. 线束经插头进入底座上的队列接线模块，再进入封闭的机脚背板。它表达事件/电气信号，不承担机械传力。
6. 双综框及筘座仍由原有三组伺服曲柄滑块驱动。固定 25/75 杆长求解与事件周期不变。

## 构图与复用边界

Loom 保留主体面积，事件刻度从左上画外延伸。保留 DSH 的既有 0.92 倍织机设计变换；本轮通过共同支架、表面和真实端点解决融合，不靠继续缩小主体挪位置。变换集中为 MOUNT token，装配点由 machinePoint 计算。

960×900 中央面板实拍已留存，但本轮没有搭建三栏工作台。未来嵌入时应让主工作区保有足够宽度，并为小标注提供局部观察；不要继续全局缩小直到图形难以辨认。

## 禁止的捷径

不使用截图作背景，不整体调透明度，不套全局滤镜，不用阴影掩盖断开的安装关系，不把独立动画端点随意连成刚性连杆，不在验证前宣称可制造或完全物理真实。
