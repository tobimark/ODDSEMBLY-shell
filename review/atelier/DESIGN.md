# Loom / 01 — 视觉重构交付说明

日期：2026-11-16。工作分支：`visual/atelier-loom`。原版基线：`master` / `00aeb56`。

## 设计结果

将“带大量遥测面板的机械线稿”重构为“近距离观看的织造装置”。机架承重、综框移动、纱线穿行、织物卷取形成连续结构。Navy 用于铸造机身和织纹骨架，Teal 用于纱线及纬线，Paper White 用于陶瓷、面板和展示背景。没有搬运 CrommaCode 的图形、字体或动画素材。

参考证据来自项目随附的 `analysis/r2-canvas-package/stills/Loom_canvas_1472x1008.png` 和 `montage/Loom_burst12_strip.jpg`。借鉴的是大面积经线、紧邻织区的机械边界，以及事件与织造的联系。原始序列采样较低，无法据此声称复现了其准确运动曲线。

## 重做的结构

| 部分 | 旧版 | 本版与设计理由 |
|---|---|---|
| 构图 | 560 px 织区，独立的大仪表面板、刻度圆弧与图样面板 | 832 px 织区（增加约 49%）；仪表内嵌左侧机身；把画面宽度交还给纱线 |
| 机架 | 近似等强度线稿、二维轮廓 | Navy 铸造立柱、顶面和返回侧面、内嵌亮金属导轨、可读的安装座和六角紧固件 |
| 纱筒 | 小型符号化纱筒 | 16 组实际绕线纹理、芯轴、挡盘、扇形出纱和陶瓷导纱器 |
| 经线 | 106 根循环彩色线 | 192 根经线，按纱筒分组，粗细及明暗有差别；线经过综眼，前后片遮挡梭子 |
| 传动 | 多个弹簧/冲量同时触发 | 单个织造周期组织开口、投梭、闭口、打纬和卷取；3:1 皮带轮与 24:16 反向齿轮 |
| 织物 | 网格和淡色行 | 逐交点绘制的 2/2 斜纹、菱形组织、浮长、纤维亮边、锁边和滚筒弯折暗部 |
| 信息界面 | 大遥测面板和悬浮控制卡 | 展签式标题、窄底部操作区、机旁阶段标注；新增 1.65× Detail 观察模式 |

预置菱形底布用于让待机状态也能读成织机。PICKS 从零开始，严格记录后续完成的工具事件；不会把预置图案伪装成真实会话输出。

## 迭代与实拍

1. **基准运行**：构建旧版并在 Edge 中实际渲染，保存 `before.png`。构建遇到 Windows 公共临时目录锁定，最终加入项目内临时目录构建脚本。
2. **第一轮**：替换主体构图、材料绘制和织物组织，保存 `iteration-01.png`。发现高分辨率 Sprite 的旋转轴偏移，以及布面盖住了底部装配件。
3. **第二轮**：修正旋转中心、织物出口和综眼位置；加入平滑卷取、前后经线遮挡、真实轮径比例的皮带切线；改进细节视图的控件留白。
4. **运行修正**：录屏测试发现旧帧间隔截断使低帧率机械变慢。现使用真实帧间隔，机构内部细分步进；回放暂停、倍率和停止同步处理。大透明纹理裁剪为实际零件尺寸，减少上传和合成开销。

## 保留与修复

保留 TypeScript / React / PixiJS、`ToolEvent`、`EventBus`、模拟器、原回放 JSON、手动触发、速度、暂停/恢复、声音及 `window.__loom` 关键入口。新增 `getMechanism()` 和 `setView()` 便于观察和验证。

修复回放启动时混入模拟事件、暂停期间回放仍注入、组件销毁时计时器/观察器残留，以及静音前初始化音频的状态一致性。Read 在新视觉语义下也对应一次完整织行；五类事件使用各自的纬线色。

验证包括构建、时序单元检查和真实浏览器交互。浏览器断言检查单画布、Play、Pause、倍率、静音、12 次连发、回放计数、Stop、三个视口以及运行错误。录屏结束应为 12 次输入、12 行完成、队列为空；具体结果见 `verification.json`：Intel Arc / Direct3D11 上 25.01 秒录制期间，1497 次动画回调，平均 59.84 fps，P95 帧间隔 16.8 ms。此前的软件渲染功能验证另存 `verification-software.json`。该数字是浏览器动画回调速率，不是跨设备帧率承诺。

## 仍有不足

- 这是具有明确顺序和遮挡关系的 2.5D 机械艺术模型，不是完整的刚体/连杆约束、纱线张力或碰撞仿真。部分联杆采用示意运动，仍可继续做工程级运动学求解。
- 当前纹理是正视超采样的程序绘制；斜视、任意旋转和更强的透视需要新的三维或网格实现。
- 本机 Intel Arc 硬件加速与 SwiftShader 软件路径均已验证，但尚未完成多硬件、多浏览器基准测试。30 fps 是录制请求值，并非跨设备的帧率保证。
- 竖屏采用全景等比缩放，主体会变小；移动端尚无专门的触摸平移与缩放设计。
- 合成声音保持可用，尚未把每次音效完全同步到打纬接触点。真实 Agent 服务适配器仍由原接口接入，本次没有新增外部连接。
