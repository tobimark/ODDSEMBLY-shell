## 1. 背景

KunlunMeta 是一个 1472×1008 设计空间的 2D 视觉引擎（React + Vite + PixiJS v8），
Loom 模式用「织机 + 事件刻度机构」把 AI 工具调用事件变成有节奏的机械动作。

本轮把左侧的事件刻度机构从**静态读数窗**改成**可回滚的动态转盘**：

- 12 槽索引鼓，每个新工具组前进 30°；
- 105 ms 显示延迟 → 180 ms `easeInOutCubic` 步进 → ≈2 s 停留；
- 固定读头（40° 针/箭头/螺栓座）不动，卡窗转到其下表示“当前读数”；
- 读数器是**结构上不可旋转**的轴对齐矩形面板，装在共享底座左下；
- 同工具事件就地聚合成 `×N`，不转轮；不同工具才步进；
- 颜色 = 当前工具（运行时采样：Read `#789ED0`、Bash `#77BA89`、Edit `#C686C0`、
  Write `#D5A868`、Search `#5AB2B6`）。

设计依据：`CrommaCode-Loom事件转盘-研究.md`（原版运行时实测）+ KunlunMeta
Precision Flat Mechanical 规范。实现说明与边界：`docs/EVENT_DIAL.md`。

## 3. 必须保留的硬约束（请勿建议移除）

1. **读数器不可旋转**：文字永远水平；所有 `Text` 不在转子子树里。反向旋转会让文字发虚。
2. **稳态零运动**：只在事件驱动下做 30° 索引步进，不做连续自转/空转。
3. **同工具 ×N 不推轮**：聚合发生在当前槽位内。
4. **原版实测时序是基线**：105 ms 显示延迟、70–200 ms 换卡、≈2 s 停留；
   当前 180 ms 是“放大可读性”的选择，允许调参但需说明依据。
5. **工具色来自运行时采样**，不是主观配色；改色需给出新证据。
6. **画布是 1472×1008 展览图纸，盘心在画布外**，只露出左上弧段——刻意的裁切构图，
   不是布局错误。

## 6. 参考事实（不要当 bug 报）

- 原版 Loom 稳态零位移；只有换卡 70–200 ms 的沿弧扫过（研究 §6）。
- 原版读数窗固定、文字水平；没有整盘自转。
- 原版没有 12 槽数字；`Sxx/12` 的 `12` 是推断（研究 §8/§9），本实现明确采用“12 槽环”。
- 当前是几何重构，不是逐像素复刻；铭牌文案（`EVENT SCALE / KH-00` 等）为自创设计。
- 读头导管、控制箱、队列牌是为“可读的机械叙事”新增的组件，不是原版观察。
