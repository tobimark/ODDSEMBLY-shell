# Loom 场景 · 三分区与壳尺寸（layout v3）

目标：**齿轮机械 / Loom 主体 / 转盘** 三个对象互不遮挡，同时按 CrommaCode 壳的
真实 GameView 尺寸设计比例。Loom 保持原尺寸（不缩小），转盘缩小到 83%，齿轮组留在左下。

## 1. 真实显示尺寸

| 项 | CSS px |
|---|---|
| 壳 stage | 1453×865 |
| CanvasWell | 730.5×743 |
| **GameView 画布** | **730×495**（井顶部；模式栏浮在画布上方 30px） |
| HUD / 四卡 | 画布下方，从 stage y≈668 起，不覆盖场景 |

设计空间 `1472×1008` → 显示 `730×495`，约 **0.496×**。设计里 1px 在壳内约 0.5px。

## 2. 三分区（设计 px）

| 区域 | bbox | 显示尺寸 | 缩放 | 说明 |
|---|---|---|---|---|
| DIAL 转盘 | x 0–470, y 0–520 | 233×258 | 0.83 | 可见弧带从左上切入，读头在 x≈135,y≈185 |
| GEAR 齿轮组 | x 270–474, y 480–775 | 101×146 | 1.0 | 飞轮 + 两级齿轮，左框外 |
| LOOM 主体 | x 484–1430, y 130–890 | 469×377 | 1.0 | 左框固定在 x=484，右边距 42px |
| READOUT | 显示 x 20–195, y 75–155 | 87×40 | 0.83 | 210×94 盘面局部，悬在蓝弧上 |

- DIAL → LOOM 顶部间隙 **17px**；GEAR → LOOM 间隙 **4–10px**；LOOM → 右边距 **42px**。
- READOUT 顶边距画布顶 75px，扣掉模式栏 30px 后实际露出 **7px**。
- 三个对象 **没有像素级重叠**；齿轮组仍在 Loom 世界内，随 Loom 一起缩放。

## 3. 读数器字号预算

| 行 | 设计字号 | 显示字号 |
|---|---|---|
| TYPE（READ/BASH/…） | 44 | **18.1px** |

- Loom 右边距只有 42 设计 px（显示 21px）；如果壳给 GameView 再留内边距，Loom 应缩到
  0.97（左框保持约 478，右边距约 134 设计 px）。
- `shell-context.png` 是合成示意：把场景截图贴进壳的 GameView 区域，并未真正接入

  0.5× 预放大，功能信息不依赖细线。
