## 1. 读数窗

- 盘面局部 `(80,170)`，245×100；0.83 盘面缩放 + 730 显示缩放后：
  **宽约 101 CSS px**；主字 **20.2px**、次数 **12.4px**、槽位 **10.7px**。
- 只显示 `TYPE / ×N / Sxx / 12`；SEARCH 六字母不截断。
- 单一外壳轮廓 + 一个内凹纸窗；没有 rotation 字段，不随转子旋转。
- 删除双层边框、底部安装轨、2 颗导轨螺栓、30°/44° 夹具、3 根连杆、读头短杆。
- 读数窗位于盘面静止结构上，压在读数器 front 层；不回到共享床身。

## 2. 730 视觉层级

主框、飞轮、传动轴、梭子、织物优先；无法在 730 识别的装饰降级。

**删除**

- 全幅 24px 点阵（约 1600 个点）、4 条目录小字、顶部 FIG/口号块。
- 读数器双层 bezel、安装轨、悬挂夹具/连杆。
- 导管 8 点 → 5 点；3 夹 → 2 夹；逐折点接头。
- 联轴器两侧的安装板堆叠。
- 螺栓六角螺纹细节（0.5x 下不可见）。

**弱化**

- 上层经线 alpha 0.58；`<8px` 微标签 alpha 0.58。
- 装饰性细线、纸张点阵、微文案不再抢主轮廓。
- 螺栓改为安静点状紧固件。

**强化**

- 主机架外轮廓 1.8px、结构 plate 外轮廓 1.5px。
- 读数窗字号/对比度；SEARCH 兼容。
- 输出轴连续中心线、联轴器键、输出轴承；键随齿轮相位旋转（3×）。
- 品牌统一：床身 `ODDSEMBLY`、机架 `ODDS / 01`、图纸 `ODDSEMBLY / EVENT LOOM 01`。

## 3. 机械连续性

- 飞轮 → 齿轮 A/B（3:1 / -4.5:1）→ 联轴器 → 输出轴 → Loom 主轴方向可见。
- 传动轴屏幕 y≈582；轴承/联轴器/输出轴承在一条水平线上；`shaftMark` 绑定 `m.angle*3`。
- 张力管 y≈430 从仪表右缘进入 Loom 左机架，带一个夹块。
- 导管从读头 `(209,248)` 到齿轮箱顶 `(235,533)`，5 点、2 夹，避开卡窗。
- 只保留上方传动轴和下方结构轨，没有第三条大连接。

## 4. 边界

- Loom `MOUNT {x:125,y:36}`、`scale 1.03`；左框 468、帧右缘 1381、最外伺服约 1421。
- 730×548 中：Loom 帧右缘约 685 CSS，最外伺服约 705 CSS，右侧余 **约 25 CSS px**；
  内容底约 517，底部余 **约 31 CSS px**。
- 齿轮箱与 Loom 左框间隙约 36 CSS px。
- 没有通过缩放整张画布来掩盖细节；Loom 仅从 1.06 收到 1.03 并左移，细节另行 LOD。
