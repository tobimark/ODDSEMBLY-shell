# Loom V7 — 三个静态整体构图方案（未实现）

状态：**暂停 V7 代码修改。** 本目录只做静态美术评审，不进入动画、事件状态机或实现。
V6 已提交的代码（`c74e2d6` / `event-dial-layout-v6`）未被修改；本轮没有新增或删除源文件。

## 0. 评审方式

- 所有机械、织物、梭子、经线、机架、齿轮、飞轮均来自**当前真实 Pixi 场景**在
  1472×1008 下的截图；不是 AI 生成的机械插画，也没有重画 Loom 主体。
- 为了看整体构图，临时在浏览器运行时隐藏了 V6 读数器、底部装配板和 V6 导管；
  **没有改代码**。这三个元素在方案里都不出现。
- 织机上经线透明度在截图中恢复为 **1.0**（V6 的 0.58 是上一轮的降淡处理）。
  本轮不复用“缩小显示就整体变淡”的做法。
- 每个方案给：
  - `X-1472.png`：1472×1008 原始设计图；
  - `X-730.png`：730×548 实际显示预览（contain 缩放、上下 24px 黑边）。
- **读数器是为构图研究绘制的静态覆盖层**，不是最终像素实现；位置、直径、字距在选定方案后
  再按真实矢量重做。

参考基准：[Astra Loom 原始主体](../../atelier/reference.png)；机械制图语言以 CrommaCode
原版的细线、刻度、固定仪表和“被画布裁切的大转盘”为准。

## 1. 三案共同处理

| 项 | 处理 |
|---|---|
| Loom 主体 | 不改结构、不改织物；只做整体位置/比例 |
| 底部装配板 | **删除**（所有方案都不出现） |
| V6 扁平读数器 | **废弃**；不沿用矩形卡片、双层边框、安装轨、夹具或连杆 |
| 新增机械件 | 无；不新增线路、导管、灯、粒子或装饰支架 |
| V6 信号导管 | 方案中不出现；不是用一条新线替代 |
| 读数器 | 统一采用 **“定子眼”圆形固定窗**：静止圆周窗、水平字、蓝色 12 刻度索引圈；直接落在固定外环上 |
| 显示 | Loom 不整体降淡；730 只做等比 contain |

### “定子眼”读数器

- 设计直径 176px（730 下约 87px），外圈 9px 固定金属壳，内部纸窗；BASH ≈21.8 / ×2 ≈12.9 / S02·12 ≈10.0 CSS px。
- 蓝色 12 刻度索引圈对应 12 槽，但不随转子转；它是固定环上的第二个小表盘。
- 只显示 `BASH / ×2 / S02 / 12`；没有文件路径、detail、age、chip。
- 读数器不再“挂”在盘面外，而是**圆窗本身成为固定环上的仪表**。
- 这是三案共用的读数语言；差异在整体构图和它与 Loom/齿轮箱的咬合关系。

## 2. 三个方案

### A — 开弧 / OPEN ARC

[1472 原始图](A-1472.png) · [730 预览](A-730.png)

- 盘面 `dial (20,10) / 0.86`；Loom `(110,25) / 1.04`。
- Loom 框约 x456–1378；最外伺服约 1418；右侧仍有安全边。
- 读数器在 **外弧最高点** `(145,155)`，圆窗与蓝色外弧同向。
- 特征：最接近 Astra 的“大转盘被画布裁切 + Loom 主体”关系；留白最多，齿轮箱、
  飞轮、Loom 三段最清楚。
- 风险：盘面只露一条弧，事件转盘的“轮”感最弱；读数器像弧上的独立小表盘，
  与齿轮箱的机械咬合最松。
- 730：Loom 宽约 457px，读数器约 87px；右余约 25px，底部约 31px。

### B — 嵌套传动 / NESTED DRIVE（建议主案）

[1472 原始图](B-1472.png) · [730 预览](B-730.png)

- 盘面 `dial (20,-30) / 0.90`；Loom `(90,35) / 1.06`。
- 盘面外环压到**齿轮箱与 Loom 左框后方**，三层轮廓互相咬合，像一台机器的
  大端盖 + 传动 + 机身。
- 读数器落在 **读头 / 传动交汇处** `(250,300)`，离齿轮箱和 Loom 最近。
- 特征：三者最像一台完整机器；Loom 比 A 大约 2%，但仍保留左侧完整传动链。
- 风险：左侧信息密度最高；盘面弧线与齿轮箱、张力表的距离最近，需要靠线宽分层。
- 730：Loom 框约 443–1382，最外伺服约 1423；读数器约 87px。

### C — 边缘仰视 / EDGE ELEVATION

[1472 原始图](C-1472.png) · [730 预览](C-730.png)

- 盘面 `dial (-200,-80) / 0.92`；Loom `(60,20) / 1.08`。
- 转盘被画布左缘切掉大半，只留下外弧和固定读数窗；Loom 最宽、最接近
  Astra 参考的仰视比例。
- 读数器在 **画布切边** `(170,190)`，像一个从侧面看到的固定仪表。
- 特征：Loom 主体最强，画面最像“一台正在工作的机器”，而不是三个部件并排。
- 风险：转盘可读性最低；读数器与左侧切边的关系很敏感，实际实现必须重新对位；
  不建议把 Loom 再放大。
- 730：Loom 框约 420–1376，最外伺服约 1418；右侧余量约 25px。

## 3. 方案对比

| | A 开弧 | B 嵌套传动 | C 边缘仰视 |
|---|---|---|---|
| 整体关系 | 三段并列 | 三层咬合 | 单机仰视 |
| Loom 占比 | 中 | 中大 | 最大 |
| 转盘可读性 | 中 | 中 | 低 |
| 读数器咬合 | 外弧独立仪表 | 读头/传动仪表 | 切边仪表 |
| Astra 接近度 | 高 | 中高 | 最高 |
| 实现风险 | 低 | 中 | 高 |
| 建议 | 保守备选 | **主推** | 大胆备选 |

**建议先按 B 深化**：它是唯一同时做到“转盘外环进入机器轮廓、读数器靠近读头、
Loom 仍然完整”的方案。A 作为安全退路，C 只作为更强构图的方向验证。
