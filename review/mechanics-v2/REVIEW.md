# Loom 评审修正版

保留首版整体构图、材料和品牌配色。本轮针对评审意见修改，不代表已经通过用户最终验收。

## 机械约束

删除黑色小齿轮与综框之间没有机械意义的连杆，也删除飞轮到筘座以及另一条综框的示意连杆。右侧新增三组明确标注 SERVO A/B/R 的伺服曲柄滑块：轴心固定，曲柄半径 25，连杆长度 75，滑块沿既有竖直导轨移动。根据滑块目标位置求两个圆的交点，得到曲柄销和伺服角度。杆长由几何保证，不会因两端独立动画而伸缩。代码位于 `src/engine/loom/atelier/linkage.ts`。

这是对传动方案的明确改变：双综框和筘座由独立伺服轴驱动，左侧齿轮不再被描绘成这些部件的直接动力源。没有宣称把旧错误连杆修成了传统的单轴机械织机。

新增测试覆盖 12,003 个姿态，检查 25/75 的固定长度、可达区间以及非法位置拒绝。它验证平面几何约束，不验证电机力矩、关节间隙、碰撞、动力学或制造可行性；后续仍需做这些工程验证。

## 密度与细节

经线从 192 减为 112，减少约 42%，维持 16 个纱筒，每筒 7 根。综丝、筘齿、标注与出纱同步调整。线宽减轻，让导轨、综框和后层构件更容易识别。织物仍保留原来的菱形组织。

## 声画同步

取消事件一进入队列就播放声音的逻辑。打纬完成、提交织行的同一个回调触发短促打纬音；排队等待不发出假打纬声。浏览器录屏直接混合真实 Canvas 视频轨与 WebAudio 输出的 Opus 音轨，不是后期配音。

浏览器验证要求：AudioContext 为 running，12 次织入对应 12 次打纬声，声音记录中的事件 ID 顺序与输入一致。`verification.json` 保存回调时间。该验证证明触发时序和音轨存在，不等于跨设备音频输出延迟已校准。

## 复核

`npm run build`、`npm test`、`npm run review:atelier`。本轮录屏和截图位于本目录。`after-hero.png` 用于检查新连杆和密度；`loom-live.mp4` 包含实际音频。历史证据 `review/atelier` 不适用于本轮机械结构。

Chips、Westworld 尚未开始实现或跨模式验证。当前不将本版声明为已经验收通过的全项目标准。
