# region-cards — 画布底部「游戏视图 + HUD + 4 张指标卡片」

> 交付物：`src/regions/Cards.tsx`（唯一改动的组件文件）+ 本文档。
> 参考帧 `.tmp/shell/ref.png`（2906×1730 native @2x）；截图 `shots/shell.png`（同尺寸，`tools/shoot.mjs`，`--disable-lcd-text` 灰度 AA）。
> 换算：`client = (native − 13) / 2`；下文所有表都同时给 native 与 client。

本块**浮在中间画布（CanvasWell）上方**：`Cards` 根节点是 `.client` 里的绝对定位透明层
（`inset:0`、`pointerEvents:none`），卡片缝隙让画布底色透出来。`<Cards />` 挂在 `App.tsx` 的
`<CanvasWell />` 之后、`<AgentPanel />` 之前。

**验收**（`tools/diff.py` 的 `CENTER_out_of_scope` 含本区域，官方 CHROME SCORE 不含它，必须单独量）：

## 6. 字体结论

全区**只有一种字体**：`Maple Mono CN 400 / 13px`（CJK 1.2em = 15.5 逻辑 px），**没有 Cromma Sans**。
`tools/fontmatch.py` 对 `游戏视图`/`AGENT`/`工具`/`工具流`/`Token 流速`/`没有后台进程`/`0.00`/`tok/s`/`MB`/`0`
逐个验证：`MapleMono-400 native=26（css 13.0）` 在中文串上稳定最高（`工具` 0.948、`MB` 0.921、`0.00` 0.823）。
垂直定位用 baseline：`line-height:13px` 时 baseline 距盒顶
`(13 − (1.02em+0.30em))/2 + 1.02em = 11.18px`（hhea: upem 1000 / asc 1020 / desc −300 / lineGap 0，OS/2 置 USE_TYPO_METRICS），
组件里 `BASELINE = 11.2`，所有文字由实测 baseline 反推 `top`。

## 9. 方法论：字形相位 / bbox 对齐 ≠ 像素最优 ★

这是本区域最反直觉、也最值钱的一条经验。

1. **参考帧的字形光栅相位和第 2 点 bbox 边缘不是一回事。** 把标题墨迹左端对准参考 bbox（origin +0.5 native）后，
   标题窗口 meanAbs **从 12.32 涨到 15.82**（更差）；箭头 bbox 对齐后 4.10 → 9.26。已回滚。
2. **native 半像素 vs 整像素相位**：把 title origin 从 `x.25/x.75 client`（= 半 native 像素）挪到整数 client（整 native）后，
   c2 title 15.69 → **21.14**、c3 title 11.73 → **17.78**；整张 `cards_only` 2.03 → **2.24**。已回滚。
   **结论：本区域文字应落在 `.25/.75 client`（半 native）相位**，与参考帧（子像素渲染）的模糊相位更接近；
   整数相位虽然 bbox 更准，但笔画变"脆"，逐像素反而差。
3. **方法**：用"墨迹掩码 + ±4 native 平移搜索"（`shift2.py`）逐元素找误差曲线的极小点，再换算成 client 偏移；
   **不要**直接对齐 bbox。注意搜索步长是整数 native，若结果把元素带离半 native 相位，要手动回到 `x.25/x.75`。

## 10. 未达标 / 不确定（诚实清单）

1. **文字抗锯齿是物理下限**：参考帧 ClearType 子像素 AA，复刻 `--disable-lcd-text` 灰度 AA。卡片行 ≈1.17 的 meanAbs 来自这里，CSS 无解。
2. **HUD 带与卡片四周的画布内容未复刻**（GameView 网点网格 + 斜向标尺线 + 纸纹），`cards_box` 里 1.2 左右来自画布，不在本区域文件范围。
   因此 ≤1.5 对该盒子不可能；已与 Lead 对齐改为 `cards_only ≤2.0`（最终 **2.02**，接受）。
3. **字形比参考帧宽 1~4 native**（同 13px、同步进），推测是原应用 GPUI 的栅格/字体版本差异；按相位最优（≈居中）摆放，右端会偏 1~2 逻辑 px。
4. **卡片圆角 14.5** 由 29 native 拟合（rms 0.69），真值可能 14/15。
5. **半透明 bleed 未复刻**（形状见 §8.3），按 Lead 判据不加遮罩。
6. `Icon.tsx` 已修好（uiIcons 优先）；本组件仍直接 import `UI_ICON_PATHS`，换 `<Icon>` 时那 4 个非整数 size 必须保留。
